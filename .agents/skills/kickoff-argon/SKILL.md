# Kickoff the garden build
1. Read `AGENTS.md` and `docs/MASTER_SPEC.md`, `docs/STORYBOARD.md`, `docs/PERFORMANCE.md`, `docs/ANIMATION_BRIEF.md`.
2. Inspect running starter and do `npm run typecheck && npm run build` before changing code; if dependency installation is pending, report exactly that and request user to run `npm install`.
3. Establish art direction. Sketch a mobile portrait frame and animation beat sheet before replacing the fallback.
4. Delegate **separate scopes** to custom subagents: `floral-3d`, `motion-director`, `mobile-ux`, `performance-qa`. Use isolated branches/worktrees if supported. Do not assume all Antigravity surfaces support automatic delegation.
5. Integrate in stages: (a) hero flower, (b) garden depth, (c) 5 interactive flowers, (d) cinematic finale, (e) QA.
6. Take mobile screenshots and measure using actual browser/device tools where available. Keep a truthful `docs/QA_REPORT.md`.
7. Never remove personal writing from content file. Report artifact, commands and remaining blockers.
